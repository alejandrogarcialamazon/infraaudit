# Changelog

## 1.1.0 — 2026-11-16 (beta)

- CPU por delta; evaluación conservadora de sincronización NTP.
- Snapshot Docker por host y consultas inspect limitadas a campos necesarios.
- HTTP/TLS con confianza, redirecciones y umbrales por servicio coherentes.
- DNS tipado A/AAAA/CNAME/MX/TXT sin depender de dig.
- Integraciones DNS y SSH reproducibles además de HTTP/TCP/TLS.
- Políticas de salida, doctor, filtros y dry-run.
- Concurrencia limitada, progreso y cancelación con evidencia parcial.
- Esquema 3.0, identidad de hallazgos, fingerprint de inventario, escritura atómica y diff.
- Locks Linux con versiones y hashes, pruebas del wheel y Docker en CI y checksums de release.
